# Cleanup notes — from Lovable template to contract-scoped Voxy frontend

This repo started as a "NeoBrutal Landing Creator" template generated by
Lovable, with the Voxy scam-detection screens added on top. It had a lot
of unrelated scaffolding left over. This pass removed everything not
required by the team's `Voxy/frontend/` contract.

## Removed

- **Auth / Dashboard / Supabase**: `pages/Auth.tsx`, `pages/Dashboard.tsx`,
  `pages/dashboard/*`, `integrations/supabase/*`, `.env` (had real Supabase
  keys), `components/AudioPanel.tsx` + `lib/audio.ts` (Supabase-dependent,
  unused by the actual upload flow — `FileDrop.jsx` handles that).
- **Marketing/landing sections**: `components/sections/*`,
  `PricingSection`, `TestimonialsSection`, `FAQSection`, `CTASection`,
  `AchievementsSection`, `TransformationSection`, `CaptureIdeasSection`,
  `HeroSection`, `ProjectsTable`, `DashboardSidebar`, `SharePostDialog`,
  `PostComposer`, `NavLink`, `DemoNotice`, `logos/`.
- **Demo/seed data**: `src/demo/*`.
- **Unused shadcn/ui library**: `components/ui/*` and its hooks
  (`use-toast.ts`, `use-mobile.tsx`) — verified nothing in the kept Voxy
  pages imports from `@/components/ui`.
- **Unused lib helpers**: `lib/share.ts`, `lib/platforms.ts`,
  `lib/validation.ts`, `lib/utils.ts` — not referenced anywhere in the kept
  code.
- **Unused assets**: `public/images/*` (all belonged to the deleted
  marketing/logo sections), `src/assets/avatar-*.jpg` (testimonials only).
- **TypeScript**: converted `vite.config.ts` → `.js`, `tailwind.config.ts`
  → `.js` (dropped the unused accordion keyframes/plugin that came with
  the deleted shadcn accordion). Removed `tsconfig*.json`,
  `vite-env.d.ts`, and the TypeScript/typescript-eslint dev dependencies.
  No `.tsx`/`.ts` files remain.
- **`package.json`**: trimmed to the 4 runtime packages actually imported
  (`react`, `react-dom`, `framer-motion`, `lucide-react`) and the minimal
  build toolchain (`vite`, `@vitejs/plugin-react-swc`, `tailwindcss`,
  `postcss`, `autoprefixer`). Removed ~30 unused packages (Radix UI,
  Supabase, react-query, react-hook-form, zod, recharts, gsap,
  embla-carousel, sonner, date-fns, etc.) along with `lovable-tagger`
  (a Lovable-editor-only Vite plugin) and `eslint.config.js` (was TS-aware
  lint config for the removed code).
- **Structure**: moved the whole frontend into `Voxy/frontend/` to match
  the team contract's monorepo layout, instead of living at repo root.

## Kept as-is (this is the actual Voxy app)

`App.jsx` state machine, `pages/Home.jsx`, `UploadPage.jsx`,
`AnalyzingPage.jsx`, `ResultsPage.jsx`, `components/Header.jsx`,
`Footer.jsx`, `Logo.jsx`, `StepIndicator.jsx`, `FileDrop.jsx`,
`RiskGauge.jsx`, `RiskMeter.jsx`, `ThreatList.jsx`, `WaveformVisual.jsx`,
`lib/api.js`, `lib/mockResult.js`, `lib/riskConfig.js`, `index.css`
(Voxy's dark forensic-security theme + animation keyframes).

All framer-motion animations, the animated risk gauge/meter, and the
scanning "analyzing" screen are untouched — they were never dependent on
any of the removed code.

## Verified

`npm install && npm run build` succeeds with no errors after every
removal in this list.
